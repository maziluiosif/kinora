Everything in one binary

A native egui interface on top of a shared Rust core. A browser UI is included too.

🧩

Addon catalogs

Speaks the Stremio addon protocol. Cinemeta and Torrentio come preinstalled, and you can add any other addon by its manifest URL.

⚡

Built-in torrent streaming

Powered by librqbit. It downloads only the file you watch, prioritizes pieces around the playhead, and supports instant seeking.

🎬

Embedded FFmpeg player

HEVC, AC3, DTS, MKV: if FFmpeg decodes it, Kinora plays it. You get audio track and subtitle selection and full screen.

⏯

Resume & up next

Continue watching with progress bars, automatic resume, watched episodes, and a prompt for the next episode near the end.

🔎

Search & discover

Search across every addon at once, browse catalogs with infinite scroll, and filter streams by quality, seeders and size.

🔒

Local & private

No account and no telemetry. The local server only answers to 127.0.0.1, and your library is a JSON file in ~/.config/kinora.

Get started

Build from source with Cargo. You need Rust 1.88+ and the FFmpeg libraries.

1 · Dependencies (macOS)

$ brew install ffmpeg pkg-config
# Debian/Ubuntu: libavformat-dev libavcodec-dev
# libswscale-dev libswresample-dev libavdevice-dev
# libavfilter-dev pkg-config libclang-dev

2 · Run

$ git clone https://github.com/maziluiosif/kinora
$ cd kinora
$ cargo run --release
# browser UI instead:
$ cargo run --release --bin kinora-web

Under the hood

A small, readable codebase with one shared core and two front ends.

addons.rs

Manifests, resource matching, catalog/meta/stream requests

engine.rs

librqbit session: magnet → file → stream

server.rs

Local HTTP API and range-request streaming

desktop/

egui shell, pages, and the FFmpeg + cpal player

web.rs

Browser UI with vanilla JS, embedded in the binary
